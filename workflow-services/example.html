The rules make the difference.

A matching enquiry ID and identical normalized content count as an exact replay. Two different records with the same ID are both held for review. A shared email alone does not make two enquiries duplicates. This example does not find near-matches or repeated enquiries with different IDs.

Whitespace and source labels are standardized. Dates are converted to UTC only when an explicit time zone is present. Missing details and ambiguous dates are flagged; they are not invented. The original file is preserved.

What this demonstrates

The example covers preparation, duplicate handling, exceptions, record counts and a repeatable handover. The same input produces the same output. Malformed files are rejected before export, rather than partly processed. The automated checks cover that rejection and preservation of prior results.

This is a batch preparation example, not a live CRM integration. “Ready” means the record passed these example rules; it does not verify a person’s identity, email deliverability or marketing consent. Production work needs your actual field mapping and approval. Cross-batch replay protection is separate integration work.

The exceptions CSV is for human review, not import. Formula-like cells are flagged and prefixed with an apostrophe, which changes their text. CSV downloads use UTF-8 with a byte-order mark. Compatibility and safe handling still need checks in the agreed destination application.
